# Frontend ImHere

## Карта сторінок

```text
Головна
├── Реєстрація учня або викладача → підтвердження адміністратора
└── Вхід
    ├── Панель адміністратора → заявки
    ├── Панель викладача
    │   ├── Групи → учасники
    │   ├── Заняття → створення → заняття з QR-кодом
    │   └── Статистика відвідуваності
    └── Панель учня
        ├── Мої групи
        ├── Сканування QR-коду → підтвердження результату
        └── Історія відвідувань
```

Сторінки — окремі HTML-файли в `frontend/`. Кожна використовує спільні `main.css`, `components.css`, `responsive.css` та ES-модулі з `frontend/js/`. Модулі відповідають за API, авторизацію, панелі, групи, заняття, QR-коди, відвідуваність і допоміжні функції. Бібліотека генерації QR зберігається локально у `frontend/vendor/`, тож браузеру не потрібно завантажувати її зі стороннього CDN. Учні й викладачі реєструються за логіном і паролем, після чого адміністратор підтверджує або відхиляє заявку. Викладач додає схваленого учня до власної групи за логіном; під час активного заняття список відміток оновлюється автоматично.

Кнопка у верхній панелі перемикає світлу й темну теми. Вибір зберігається в `localStorage` цього браузера. Основні кольори інтерфейсу визначені CSS-змінними в `frontend/css/main.css`.

## Схематичні макети

```text
Публічна сторінка:    логотип                       вхід | реєстрація
                      заголовок і короткий опис
                      [увійти] [створити обліковий запис]

Авторизація:          логотип
                      [форма: логін, роль, пароль, кнопка]
                      повідомлення про результат | посилання на іншу форму

Панель:               логотип     логін користувача               вихід
                      заголовок сторінки та короткий опис
                      [метрика] [метрика] [метрика]
                      [основний список / таблиця]

Адміністратор:         логотип     логін користувача              вихід
                      [заявки учнів і викладачів]
                      [підтвердити / відхилити]

QR викладача:         логотип     стан заняття                   вихід
                      [QR-код і таймер] [інструкція та стан]

Сканер учня:          логотип     логін користувача               вихід
                      [відеопотік + вибір камери]
                      [увімкнути / зупинити] [ручний токен JSON]
                      підтвердження результату та історія
```

## Налаштування API

Перед публікацією вкажіть origin Worker у `frontend/js/config.js`, наприклад:

`frontend/js/config.js` уже вказує на опублікований Worker: `https://imhere-api.ilya64misko.workers.dev`.

Це публічна адреса API, а не секрет. Точне джерело frontend має бути вказане у `ALLOWED_ORIGINS` Worker. Під час локальної розробки API автоматично спрямовується на `http://localhost:8787`.

## Публікація

Репозиторій зберігає сайт у `frontend/`, тоді як публікація Pages із гілки підтримує лише `/` або `/docs`. Для публікації з окремого каталогу додано `.github/workflows/deploy-pages.yml`: під час надсилання змін до `main` він завантажує в Pages лише `frontend/`.

У Settings → Pages виберіть Build and deployment → Source → GitHub Actions. Після надсилання змін до `main` відкрийте Actions і дочекайтеся завершення `Deploy ImHere frontend to GitHub Pages`. Адреса матиме формат `https://sallyghost.github.io/ImHere/`. Workflow не змінює налаштувань репозиторію й запускається після надсилання змін.

## Перевірка адаптивності

Контрольні ширини: 360, 390, 768, 1366 і 1920 px. Для головної сторінки та входу перевірено відсутність горизонтального переповнення. CSS перебудовує сітки в одну колонку на мобільних пристроях, а вікно камери отримує вертикальне співвідношення сторін і достатню висоту.

Камера браузера працює лише через HTTPS (або на localhost). Якщо камеру заборонено чи вона недоступна, QR-токен можна вставити вручну; сервер виконує ті самі перевірки підпису, часу та членства в групі.
