# Локальна демонстрація ImHere

Інструкція запускає мініверсію на локальній D1-базі. Вона не змінює віддалену базу чи Cloudflare Worker.

## Підготовка

1. Переконайся, що встановлені залежності з `backend/package-lock.json` (`cd backend; npm ci`).
2. Переконайся, що `backend/.dev.vars` містить локальні `AUTH_PEPPER` і `QR_SECRET` завдовжки щонайменше 32 символи. Не додавай цей файл у Git.
3. Застосуй міграції локально:

   ```powershell
   cd Q:\ImHere\Imhere\backend
   npx wrangler d1 migrations apply imhere-db --local
   ```

## Запуск

У першому терміналі:

```powershell
cd Q:\ImHere\Imhere\backend
npm run dev
```

У другому терміналі:

```powershell
cd Q:\ImHere\Imhere\backend
npx wrangler pages dev ..\frontend --port 5500
```

Відкрий `http://localhost:5500`. На порту 5500 цей frontend звертається до локального Worker на порту 8787.

## Облікові записи та сценарій

1. Після міграцій створи локального адміністратора: `cd Q:\ImHere\Imhere\backend`, потім `npm run create:local-admin`. Команда додає акаунт тільки до локальної D1.
2. Відкрий `admin.html`, щоб схвалити заявки, або створи викладача локально командою `npm run create:local-teacher`.
3. Зареєструй учня та за потреби викладача на сторінці ImHere; адміністратор має схвалити заявки.
4. Увійди як викладач, створи групу та додай схваленого учня за логіном.
5. Створи заняття, запусти його й відкрий QR-код.
6. Увійди як учень в іншому браузері або профілі, відскануй QR та перевір підтвердження.
7. Повернись до сторінки заняття викладача: список відміток оновлюється автоматично.
8. Зміни статус вручну, вистав оцінку, заверши заняття та переконайся, що не відмічені учні отримали статус «Відсутній», а нові QR-відмітки більше не приймаються.
9. Переглянь середній бал і статуси в історії учня.

Для інтеграційних перевірок залиш Worker запущеним і в третьому терміналі виконай `cd Q:\ImHere\Imhere\backend`, потім `npm run test:security`.
